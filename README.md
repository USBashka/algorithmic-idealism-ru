Это независимый русский перевод обзорной статьи об **алгоритмическом идеализме** — подходе к основаниям физики, который начинает не с вопроса «что существует во внешнем мире?», а с вопроса «какого опыта агенту следует ожидать следующим?».

Статья связывает квантовую теорию, алгоритмическую вероятность и философию личной идентичности, а затем применяет получившуюся картину к больцмановским мозгам, сценарию друга Вигнера, телетранспортации Парфита и гипотезе симуляции.
